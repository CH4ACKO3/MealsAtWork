# Meals at Work / 工作餐

[GitHub](https://github.com/CH4ACKO3/MealsAtWork) · [下载](https://github.com/CH4ACKO3/MealsAtWork/releases) · [创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3796904995)

在进行制作或研究工作时，如果小人感到饥饿，就会“点餐”。负责搬运的小人会为其配送餐食，让工作者可以在工作台上用餐，节约往返餐厅的时间。

- **自动送餐**：有配送人手时自动下单，按每位工作者的饮食安排挑选餐食。
- **一趟多送几份**：一次领取多个订单，集中取餐后连续送达。
- **边工作边吃饭**：收到餐食后就地用餐，以稍慢的速度继续制作或研究。
- **安心午休**：制作途中也可以自动外出吃饭，回来接着完成手上的作品。
- **灵活利用空间**：空闲工作台也能作为临时用餐位置，综合考虑距离与餐桌偏好。
- **按喜好调整**：工作台用餐的轻微心情影响、用餐方式和配送等待时间均可设置。

殖民者、具备搬运工作能力的机械体和训练过搬运的动物都可以配送餐食。拥有食物需求的玩家机械体也能享用工作餐。

支持 **RimWorld 1.6**，需要 **Harmony**。提供 Common Sense、Pick Up And Haul、Schedule Everything 兼容适配和简体中文。原名 Desk Lunch。
