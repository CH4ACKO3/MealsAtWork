# Meals at Work 0.6.2

- Couriers use the game's immediate-touch rules at pickup and delivery, correctly routing around blocked corners.
- Release source meal reservations after pickup so remaining food is available and recipients can eat delivered meals promptly.
- Resize reservations when pending orders are cancelled. If reserving the remaining quantity fails, release the affected orders while continuing delivery of loaded meals.
- Full carrying capacity remains a temporary state; order eligibility retains its existing behavior.
